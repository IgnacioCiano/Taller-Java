# Taller Java - Practico 1

Proyecto Maven base para ejercicios de Java.

## Requisitos

- Java 21 o superior
- Maven 3.9+ instalado en el sistema

## Comandos

- Compilar: `mvn compile`
- Ejecutar tests: `mvn test`
- Empaquetar: `mvn package`
- Ejecutar la aplicación: `mvn exec:java` si luego se agrega el plugin correspondiente
